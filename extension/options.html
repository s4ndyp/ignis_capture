Instellingen

Direct naar Ignis (standaard) of fallback via je Docker capture-proxy.

Direct: extensie roept /api/fs/writeFile op Ignis aan. Chrome vraagt toestemming voor die host (host_permissions / optional). Bij self-signed HTTPS: open Ignis eerst in een normale tab en accepteer het certificaat.

Docker proxy: zelfde als de web-app — URL van je docker compose service, pad /ignis-api/ wordt automatisch gebruikt.

Snelkoppelingen: posities 1–9 worden in Ignis geopend via het commando Notebook Navigator: Open shortcut N (map/tag/zoek/notitie). Notities op positie 10+ openen via Ignis-URL.

Laden: chrome://extensions → Ontwikkelaarsmodus → Uitgepakt laden → map extension/.
